# 区块链+AI智能股票预测平台

## 项目概述
这是一个面向股票投资者的「智能预测+社区交流+数据存证」一体化平台，兼顾专业性与易用性。

## 技术栈
- **前端**: HTML5 + CSS3 + JavaScript + Bootstrap 5 + Chart.js
- **后端**: Python (Flask) + Modb数据库
- **特色功能**: 区块链存证、AI预测引擎、社区互动

## 核心功能
1. **用户认证系统** - 注册/登录/个人中心
2. **股票数据展示** - 实时行情、K线图、财务指标
3. **AI智能预测** - 趋势预测、置信度分析
4. **社区互动** - 预测分享、话题讨论、排行榜
5. **区块链存证** - 预测记录上链、数据验真
6. **积分系统** - 预测奖励、积分兑换

## 快速开始
1. 克隆项目到本地
2. 运行 `npm install` 安装依赖
3. 运行 `npm start` 启动开发服务器
4. 访问 `http://localhost:8080`
